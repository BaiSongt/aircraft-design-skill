# 飞机重量特性理论

## 1. 重量特性概述

重量特性参考Nicolai进行计算。其计算公式主要基于经验公式总结。飞机重量特性包括结构重量、系统设备重量、推进系统重量等。

## 2. 结构重量

### 2.1 机翼结构重量

**计算公式**：
```
W_wing = 0.036 × S_wing^0.758 × W_FW^0.0035 × (AR / (cos²(ΛLE)))^0.6 × q^0.006 × λ^0.04 × (100 × tc / cos(ΛLE))^(-0.3 × (N_z × W_FW) / (S_wing × 100))^0.3
```

其中：
- `K_var`：机翼可变后掠角因子，=1对于固定翼，=1.175对于可变后掠翼
- `t/c`：机翼相对厚度
- `W_FW`：最大起飞重量
- `ΛLE`：机翼前缘后掠角
- `λ`：机翼梯形比
- `AR`：机翼展弦比
- `S_wing`：机翼参考面积（ft²）
- `N`：极限过载因子
  - =13.5对于战斗机（基于设计过载限制为9和1.5倍的安全裕度）
  - =4.5对于战斗机和运输机（基于设计过载限制为3）

### 2.2 机身结构重量

军机和一些其它飞机（增压体积与机身总体积的相比较小）可划归为无增压机身。对于这类机身，影响机身结构重量的主要因素为机身几何特征和后机身承受的载荷。

**计算公式**：
```
W_fuselage = 0.039 × (S_fuselage_gross)^1.2 × (W_FW)^0.1 × N_z^0.25 × L^0.5 × (d/L)^0.1 × (q / 100)^0.28
```

其中：
- `q`：机身承受的最大动压（lb²/ft²），可通过巡航设计点来进行计算
- `L`：机身长度（ft）
- `H`：机身的最大高度（ft）
- `K_INL`：进气道安装位置的因子
  - =1.25进气道安装在机身上
  - =1进气道未安装在机身上

### 2.3 尾翼结构重量

尾翼重量在全机重量中的占比通常各小于3%，尽管它在全机重量中的占比较小，但对重心的纵向位置却具有较大影响。影响尾翼重量的主要因素是尾翼的面积和最大设计速度。

#### 2.3.1 平尾结构重量

**计算公式**：
```
W_horizontal_tail = 0.0379 × K_var × (1 + F_H / L_H)^(-0.25) × (N_z × W_FW)^0.339 × S_HT^0.886 × (AR_HT)^0.223 × (t_RHT / c_wing)^(-0.317 × (L_H / c_wing)^(-0.119)
```

其中：
- `N`：极限过载因子
- `S_HT`：平尾参考面积（ft²）
- `t_RHT`：平尾翼根翼型相对厚度
- `c_wing`：机翼的平均气动弦长（ft）
- `L_t`：平尾尾力臂，从机翼1/4平均启动弦长到平尾的1/4平均气动弦长的纵向距离（ft）
- `b_HT`：尾翼展长（ft）

#### 2.3.2 垂尾结构重量

**计算公式**：
```
W_vertical_tail = 0.0026 × (1 + h_T / h_V)^0.225 × (N_z × W_FW)^0.556 × S_VT^0.876 × (AR_VT)^0.354 × (λ_VT)^0.019 × (1 / cos(Λ_VT))^0.319 × (S_r / S_VT)^0.139 × (L_V / c_wing)^(-0.273)
```

其中：
- `h_T/h_V`：平尾安装方式
  - =1对于T型平尾
  - =0对于安装在机身上的平尾
- `S_VT`：垂尾的参考面积（ft²）
- `M_0`：海平面最大马赫数，可通过巡航点动压等效
- `L_t`：垂尾尾力臂，从机翼1/4平均启动弦长到垂尾的1/4平均气动弦长的纵向距离（ft）
- `S_r`：方向舵面积，若尚未清楚，则取为S_r/S_VT = 0.3
- `AR`：垂尾的展弦比
- `λ`：垂尾的梯形比
- `Λ_VT`：垂尾的1/4弦线后掠角

### 2.4 起落装置重量

起落装置重量包括起落架结构以及相关液压作动系统的重量。

**计算公式**：
```
W_landing_gear = 0.043 × (W_FW)^0.882
```

### 2.5 燃油系统重量

燃油系统重量由油箱重量、油箱支撑结构重量、空中加油系统重量、燃油排放系统重量、重心控制系统组成。

#### 2.5.1 自密封油箱重量

自密封油箱通常用于战斗机油箱，其重量计算公式为：
```
W_self_sealing = 0.020 × FGW + 0.016 × FGF
```

其中：
- `FGW`：机翼油箱体积（加仑）
- `FGF`：机身油箱体积（加仑）

#### 2.5.2 油箱支撑结构重量

**计算公式**：
```
W_supports = 0.009 × FGW + 0.006 × FGF
```

#### 2.5.3 空中加油系统重量

**计算公式**：
```
W_refuel = 0.004 × (FGW + FGF)
```

#### 2.5.4 燃油排放系统重量

燃油排放系统用于遇到紧急情况战斗机需要迅速排放燃油，其重量计算公式为：
```
W_dump_and_drain = 0.001 × (FGW + FGF)
```

#### 2.5.5 重心控制系统重量

重心控制系统（包括燃油传输泵和燃油监测器）重量计算公式为：
```
W_transfer_pumps_and_monitor = 0.002 × (FGW + FGF)
```

## 3. 推进系统重量

推进系统重量是指包含发动机裸机、燃油系统、安装挂架、进排气系统、短舱、螺旋桨等组成。

### 3.1 推进系统总重量

推进系统重量与发动机净重有关，计算公式如下：
```
W_propulsion = W_engine × n × C_eng
```

其中：
- `W_engine`：单台发动机裸机重量
- `n`：发动机数量
- `C_eng`：推进系统的安装系数

**推进系统安装系数C_eng的参考值**：

| 飞机类型 | C_eng的值 |
|---------|----------|
| 喷气式公务机和运输机 | 1.56 |
| 超声速飞机（进气道形状可调节） | 2.0 |
| 配装涡桨发动机的运输机 | 2.25 |
| 通用航空飞机（配装二个活塞式发动机） | 1.80 |
| 其它类型的飞机 | 1.4 |

### 3.2 发动机控制系统重量

**计算公式**：
```
W_engine_control = 0.015 × W_engine × n × K_ECO × (L_f / 10)^0.5
```

其中：
- `L_f`：机身长度
- `N_E`：发动机数量
- `K_ECO`：发动机种类因子
  - =0.686为无加力燃烧室发动机类型
  - =1.080为含加力燃烧室发动机类型

### 3.3 发动机启动系统重量

**计算公式**：
```
W_engine_start_system = 0.005 × W_engine × n
```

## 4. 其他系统设备重量

### 4.1 控制系统重量

控制系统重量包括飞机上所有的控制装置以及液压、气动系统。

**计算公式**：
```
W_control = K_SC × (W_FW)^0.637 × (N_z × W_FW / S_wing)^0.324 × (b_wing / 100)^0.5 × (N_c + N_p)^0.5
```

其中：
- `K_SC`：控制因子
  - =106.1为没有平尾以升降副翼控制
  - =138.18为对于正常平尾控制
  - =167.48为可变后掠翼

### 4.2 仪表显示系统

#### 4.2.1 飞行仪表显示系统

**计算公式**：
```
W_instruments_flight = 0.012 × W_FW
```

#### 4.2.2 发动机仪表显示系统

**计算公式**：
```
W_instruments_engine = 0.005 × W_engine × n
```

#### 4.2.3 其他显示设备

**计算公式**：
```
W_instruments_mis = 0.001 × W_FW
```

### 4.3 航电系统

航电系统包括航电设备、对应的电气系统。航电设备重量可参考下表取，也可取作最大起飞重量的1%。

**航电设备重量**：

| 设备类型 | 重量（lb） |
|---------|-----------|
| 雷达系统 | 300-500 |
| 通信系统 | 50-100 |
| 导航系统 | 50-100 |
| 电子战系统 | 200-400 |
| 飞行控制系统 | 100-200 |

**电气系统计算公式**：
```
W_electrical_system = 0.008 × (W_FuelSystem + W_TRON)
```

其中：
- `W_FuelSystem`：燃油系统重量
- `W_TRON`：航电设备重量

### 4.4 设备重量

#### 4.4.1 弹射座椅重量

**计算公式**：
```
W_ejection = 0.088 × N_CR × (q / 100)^0.5
```

其中：
- `N_CR`：全体乘员人数
- `q`：最大动压

#### 4.4.2 杂项设备重量

杂项（包括紧急设备）设备重量计算公式为：
```
W_mis = 0.001 × W_FW
```

### 4.5 空调和防结冰系统

空调和防结冰系统用于确保机舱内的舒适性和飞机的安全性。

**计算公式**：
```
W_air_conditioning = 0.002 × W_FW
```

## 5. 复合材料应用的重量修正

现在越来越多的飞机结构中采用了先进的复合材料。复合材料由于其高比强度和比刚度的特性，可有效降低飞机的结构重量。很多先进复合材料发展研究和飞机概念设计都表明复合材料能减轻主要结构重量25%，减轻次要结构重量40%。

基于给定的55%复合材料利用率，可以在概念阶段按照部件进行复合材料修正。采用其他比例的复合材料利用率，同样可以按照55%的比例相应改变。

**复合材料结构的重量减重修正系数**：

| 部件 | 减重系数 |
|-----|---------|
| 机翼 | 25% |
| 平尾/垂尾 | 25% |
| 机身 | 10% |
| 起落架 | 8% |
