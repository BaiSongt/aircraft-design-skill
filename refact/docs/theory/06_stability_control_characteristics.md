# 飞机操稳特性理论

## 1. 操稳特性概述

操稳是飞机衡量的重要指标之一，主要指的是飞机的操纵性与稳定性。尾翼是保证飞机操稳特性的主要部件，机翼的设计参数、操纵面的设计参数和重心位置等也会影响飞机的操稳特性。

### 1.1 稳定性分类

飞机的稳定性包括静稳定性与动稳定性两方面：

- **静稳定性**：处于平衡状态的飞机受到瞬时小扰动是否具有回到平衡状态的趋势
- **动稳定性**：飞机收到扰动后回到或背离平衡状态的动态过程

### 1.2 操纵性分类

飞机的操作性也包括静操作性与动操作性：

- **静操纵性**：为了改变飞机姿态所需的舵偏角及方向
- **动操纵性**：偏转舵偏角后飞机姿态改变的过程

## 2. 静稳定性

### 2.1 纵向静稳定性

#### 2.1.1 静稳定裕度

静稳定裕度反映了飞机俯仰静稳定性的程度，可以通过比较气动中心和重心位置，计算出静稳定裕度。而气动中心位置取决于纵向力矩系数导数CMα。

#### 2.1.2 机翼类部件焦点计算

焦点是飞机操稳指标重要的计算参数之一，参考Raymer总体阶段估算翼面类部件焦点的工程算法，具体如下：

**机翼焦点位置**：
```
x_ac_wing = 0.25 × MAC_wing
```

其中：
- `MAC_wing`：机翼平均气动弦长

#### 2.1.3 平尾下洗角计算

由于机翼的下洗流存在，平尾的当地迎角会小于实际的来流迎角，导致平尾的升力线斜率相对于来流下降；同时，机翼前方的上洗和后方的下洗又会对机身产生一些额外的气动力矩。

**亚声速下洗角随迎角的变化率**：
```
dε/dα = 4.44 × (S_wing / (π × b_wing × l_ht)) × (AR_wing / (AR_wing + 2 × cos(Λ_c/4))) × (cos(Λ_c/4) / cos(Λ_c/2))^0.5 × (1 + (z_ht / b_wing))^0.33
```

其中：
- `ε`：下洗角
- `α`：来流迎角
- `Λ_c/4`：机翼1/4弦线后掠角
- `AR_wing`：机翼展弦比
- `S_wing`：机翼面积
- `b_wing`：机翼展长
- `z_ht`：平尾参考水平面先对于机翼参考水平面的高度
- `l_ht`：机翼到平尾的尾力臂

**超声速下洗角随迎角的变化率**：
```
dε/dα = 4.44 × (S_wing / (π × b_wing × l_ht)) × (AR_wing / (AR_wing + 2 × cos(Λ_c/4))) × (1 / β)
```

其中：
- `β`：压缩性因子，β = √(M² - 1)

#### 2.1.4 机身CLa与Cma计算

在机身计算过程中，由于通常的工程算法均应用于回转体机身，因而此处将机身依照面积等效为回转体。

**亚声速机身CLa**：
```
CLa_fuse = 2 × π × (A_fuse / S_wing) × (k2 - k1) × (AR_wing / (AR_wing + 2))
```

其中：
- `k2 - k1`：根据机身的长细比查询
- `V_fuse`：机身体积
- `S_0`：x0处的机身截面积
- `x0`与`x1`位置相关，其中`x1`定义为机身面积变化率负值最大的截面

**超声速机身CLa**：
```
CLa_fuse = 2 × (A_fuse / S_wing) × (1 / β)
```

其中：
- `A_fuse`：机身最大截面积

**机身Cma**：

亚声速：
```
Cma_fuse = Cma_wing_wash + Cma_fuse_self
```

其中：
- `Cma_wing_wash`：机翼上下洗影响下的力矩系数
- `Cma_fuse_self`：机身本身不受扰动下存在的力矩系数

#### 2.1.5 纵向静稳定性计算

由于机翼尾翼一般情况下均是对称翼型，所以机翼尾翼的零升力矩均为0，对重心取力矩得到：

```
M = L_wing × (x_cg - x_ac_wing) + L_ht × (x_cg - x_ac_ht)
```

无量纲化：
```
Cm = CL_wing × (x_cg - x_ac_wing) / MAC_wing + CL_ht × (x_cg - x_ac_ht) / MAC_wing
```

并对迎角求导：
```
Cma = CLa_wing × (x_cg - x_ac_wing) / MAC_wing + CLa_ht × (x_cg - x_ac_ht) / MAC_wing
```

全机焦点，即中性点为：
```
x_np = (CLa_wing × x_ac_wing + CLa_ht × x_ac_ht) / (CLa_wing + CLa_ht)
```

静稳定裕度：
```
SM = (x_np - x_cg) / MAC_wing
```

### 2.2 航向静稳定性

#### 2.2.1 航向静稳定性判据

飞机是否具有航向静稳定性与在平衡点处的力矩系数曲线斜率有关。航向静稳定性的判据为偏航力矩系数导数Cnβ，当Cnβ > 0时，具有航向静稳定性。

#### 2.2.2 垂尾侧洗角计算

同平尾收到机翼的下洗角，垂尾也会受到机翼的侧洗角。

```
σ = (q_wing / q_vt) × (z_wing / l_vt) × (dε/dα)
```

其中：
- `q`：对应各自下标的动压
- `z_wing`：机翼的参考水平面坐标

#### 2.2.3 侧力系数计算

**机身侧力系数**：
```
Cyβ_fuse = -CLa_fuse
```

**机翼侧力系数**：
```
Cyβ_wing = -CLa_wing × (Γ / 57.3)
```

其中：
- `Γ`：机翼上反角

**V尾侧力系数**：
```
Cyβ_vtail = CLa_vtail × cos(Γ_vtail)
```

#### 2.2.4 偏航力矩系数计算

**机身偏航力矩系数**：
```
Cnβ_fuse = -0.0015 × (l_fuse / d_fuse) × (A_fuse / S_wing)
```

其中：
- `d_fuse`：机身的等效直径
- `w_fuse`：取为机身的最大高度

**机翼偏航力矩系数**：

亚声速：
```
Cnβ_wing = -CL × (AR_wing / (AR_wing + 4 × cos(Λ_c/4))) × (tan(Λ_c/4) / (AR_wing + 4 × cos(Λ_c/4)))
```

其中：
- `CL`：参考升力系数，为1度迎角对应的机翼升力系数

超声速：
```
Cnβ_wing = -CL × (1 / (AR_wing × β))
```

**平尾偏航力矩系数**：
平尾偏航力矩系数计算方法同机翼。

#### 2.2.5 航向静稳定性计算

通过上述各部件的分析，类似纵向静稳定性导数的推导，可以得到全机对重心的航向偏航力矩系数对侧滑角的导数为：

```
Cnβ = Cnβ_wing + Cnβ_ht + Cnβ_vt + Cnβ_fuse
```

### 2.3 横向静稳定性

#### 2.3.1 横向静稳定性判据

飞机横向静稳定性的判据为滚转力矩系数导数Clβ，当Clβ < 0时，具有横向静稳定性。

#### 2.3.2 机翼横向力矩系数

**亚声速**：
```
Clβ_wing = Clβ_sweep + Clβ_sweep_compression + Clβ_AR + Clβ_dihedral + Clβ_dihedral_compression
```

其中：
- `Clβ_sweep`：机翼后掠角产生的贡献
- `Clβ_sweep_compression`：后掠角对压缩性因子的修正
- `Clβ_AR`：机翼展弦比、梯形比产生的贡献
- `Clβ_dihedral`：单位上反角产生的贡献
- `Clβ_dihedral_compression`：上反角对压缩性因子的修正

**超声速**：
```
Clβ_wing = -CL × (1 / (AR_wing × β)) × (tan(Λ_c/4) / (AR_wing + 4 × cos(Λ_c/4)))
```

#### 2.3.3 平尾横向力矩系数

平尾横向力矩系数计算方法同机翼。

#### 2.3.4 机身横向力矩系数

```
Clβ_fuse = Clβ_wingfuse + Clβ_fuse_induced
```

其中：
- `Clβ_wingfuse`：机翼机身滚转力矩系数
- `Clβ_fuse_induced`：机身对机翼高度的诱导效应

#### 2.3.5 横向静稳定性计算

通过上述各部件的分析，类似纵向静稳定性导数的推导，可以得到全机对重心的横向偏航力矩系数对侧滑角的导数为：

```
Clβ = Clβ_wing + Clβ_ht + Clβ_vt + Clβ_fuse
```

## 3. 动稳定性分析

### 3.1 惯性矩的计算

动稳定性与飞机的惯性矩相关，惯性矩在总体阶段由于内部布置尚未明确，通常无法准确得出，参考Raymer对飞机的xyz轴惯性矩的估计公式，如下：

```
Ix = (W_FW / g) × (b_wing / 10)² × kx
Iy = (W_FW / g) × (l_fuse / 10)² × ky
Iz = (W_FW / g) × ((b_wing + l_fuse) / 20)² × kz
```

其中：
- 对于战斗机，kx = 0.23，ky = 0.38，kz = 0.52

### 3.2 典型二阶系统介绍

在动稳定性分析中，通常将复杂的运动模态分解为简单的运动模态。

**典型的二阶系统的微分方程**：
```
x'' + 2 × ζ × ω_n × x' + ω_n² × x = 0
```

**特征根形式**：
```
λ = -ζ × ω_n ± ω_n × √(ζ² - 1)
```

**解得的特征根**：
```
λ1,2 = -ζ × ω_n ± ω_n × √(ζ² - 1)
```

**微分方程的解**：
- 当ζ > 1时，系统过阻尼，两个实根
- 当ζ = 1时，系统临界阻尼，两个相等实根
- 当0 < ζ < 1时，系统欠阻尼，一对共轭复根

### 3.3 纵向动稳定性

#### 3.3.1 纵向小扰动方程

纵向扰动运动方程的具体形式为：

```
Xu × u + Xw × w - g × cos(θ0) × θ = 0
Zu × u + Zw × w + (u0 + Zw) × q - g × sin(θ0) × θ = 0
Mu × u + Mw × w + Mq × q - Mα_dot × α_dot = q
0 × u + 0 × w + 1 × q = θ'
```

对于稳定性问题，考虑存在初始扰动下不进行操纵的运动。即δe = 0。

#### 3.3.2 动导数

**CTu/CDu/CLu**：
此处可直接基于气动模型和推力模型，输入当前速度点和后向速度小量的点，进行简单的差分来计算。

**CLq与Cmq**：
俯仰角速度引起的升力系数和俯仰力矩系数计算如下，主要评估了由于飞机俯仰角速度在平尾处产生额外的气流速度，在平尾处产生的阻尼力矩。全机可以看作平尾的阻尼力矩增加10%-25%。

**洗流时差导数**：
洗流时差导数是由于当迎角变化时，翼身组合体自由涡要经过时刻才能影响到平尾区的扰流。

#### 3.3.3 纵向模态分解

**长周期模态**：
长周期模态反应时间长，可以认为迎角和飞行法向速度依据恢复到未扰动平衡状态，近似认为迎角及以俯仰角速度变化均为0。

**短周期模态**：
短周期模态主要表现在扰动恢复的初期阶段，可以近似认为速度变化量为0。

### 3.4 横航向动稳定性

#### 3.4.1 横航向小扰动方程

横航向小扰动运动方程的具体形式为：

```
Yv × v + Yp × p + Yr × r + g × cos(θ0) × φ = 0
Lv × v + Lp × p + Lr × r = p'
Nv × v + Np × p + Nr × r = r'
```

对于稳定性问题，考虑存在初始扰动下不进行操纵的运动。即δa = δr = 0。

#### 3.4.2 动导数

**Clp**：
滚转角速度引起的滚转力矩系数计算如下，主要评估了由于飞机滚转角速度在机翼、平尾、垂处产生额外的气流速度，在对应处产生的阻尼力矩。

**Cnr**：
偏航角速度引起的偏航力矩系数计算如下，主要评估了由于飞机偏航角速度在垂尾处产生额外的气流速度，在垂尾处产生的阻尼力矩。

#### 3.4.3 横航向模态分解

**螺旋模态**：
体现为滚转角和偏航角的缓慢变化，忽略侧力方程。

**滚转收敛模态**：
滚转收敛模态体现在扰动恢复的初始阶段，近似认为侧滑角和偏航角速度的变化量为0。

**荷兰滚模态**：
荷兰滚模态体现在偏航/侧滑的振荡，在式中略去滚转力矩方程。

## 4. 静操纵性分析

### 4.1 操纵性导数计算

#### 4.1.1 简单后缘增升/控制舵面法向力系数计算

参考Datcom，二维翼型在偏转舵面后，产生的法向力系数计算如下：

```
CNδ = (CNα) × (δ / 57.3) × K'
```

其中：
- `δ`：舵面偏转角
- `CNα`：给定翼型厚度和弦长比的理论法向力系数，查图可得
- `K'`：是对舵偏角较大时的非线性修正，查表可得

三维法向力系数同上述增升装置的计算公式。

#### 4.1.2 增升压心位置

在确定舵面偏转产生的法向力之后，还需要知道力作用的位置，才能计算得到力矩。

参考Raymer：
```
x_cp = x_hinge + 0.5 × c_flap
```

基于上述法向力和压心位置即可计算舵面产生的操纵力矩。

### 4.2 静操纵性分析

#### 4.2.1 典型1g状态配平

正常1g平飞需要凭借平尾进行配平，其静力方程为：

```
L_wing + L_ht = W
M_wing + M_ht = 0
```

可解得配平迎角以及平尾舵面偏转角。

#### 4.2.2 定常拉伸配平

过载为n拉起时同样需要凭借平尾进行配平，其静力方程为：

```
L_wing + L_ht = n × W
M_wing + M_ht = 0
```

可解得配平迎角以及平尾舵面偏转角。

#### 4.2.3 起飞着陆配平

起飞着陆需要计算平尾偏角为多少时才能抬头，此时飞机前起落架支持力为0，后起落架承受全部支持力。

其中：
- `δ_f`：襟翼偏角
- `δ_e`：升降舵偏角

可计算平尾最小偏转角及对应得支持力。

#### 4.2.4 侧风分析

在着陆过程中突发侧风的情况下飞机要满足配平能力，侧风参考民机取0.2失速速度。

可解得配平迎角以及平尾舵面偏转角、副翼偏转角。
