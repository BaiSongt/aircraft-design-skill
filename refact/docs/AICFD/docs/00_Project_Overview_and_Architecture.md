# 项目概述与系统架构

## 1. 项目愿景

本项目旨在开发一个**AI驱动的计算流体动力学（AICFD）智能体（Agent）**。该Agent能够自动化执行飞行器空气动力学性能的CFD计算全流程，并通过集成AI代理模型（Surrogate Model）实现高精度计算与实时预测的结合，最终赋能于飞行器的快速设计、分析与优化。

## 2. 核心功能

*   **自动化工作流**: 无人干预地完成从几何输入到结果输出的CFD计算。
*   **参数化驱动**: 接收参数化输入（如几何参数、流动条件），自动执行对应模拟。
*   **过程监控**: 实时监控计算收敛性与系统资源，具备错误处理与超时中断能力。
*   **自动报告**: 每次计算后自动生成包含关键结果与图表的可视化报告。
*   **AI集成**: 内嵌AI代理模型，提供“实时预测”模式。
*   **循环迭代**: 能够按预设参数空间自动循环，为AI模型训练生成大规模数据集。

## 3. 系统架构设计

本系统采用模块化设计，分为以下几个核心组件：

```
+--------------------------------------------------------------------------+
|                       User Interface / API Layer                         |
|                    (e.g., RESTful API, Web GUI, CLI)                     |
+--------------------------------------------------------------------------+
                                     | (JSON Request)
                                     v
+--------------------------------------------------------------------------+
|                           AICFD Agent (Core Logic)                       |
|                                (Python)                                  |
|                                                                          |
|   +---------------------+   +----------------------------------------+   |
|   |   Task Dispatcher   |-->|           Execution Engine             |   |
|   | (Mode: 'accurate'/'fast')|                                        |   |
|   +---------------------+   |   +--------------------------------+   |   |
|              |              |   |      CFD Workflow Manager      |   |   |
|              |              |   | (Template, Mesh, Solve, Post)  |   |   |
|              |              |   +--------------------------------+   |   |
|              |              +------------------^-----------------+   |   |
|              |                                 |                    |   |
|              | (Real-time Prediction)          | (High-fidelity Calc) |   |
|              v                                 v                    |   |
|   +---------------------+        +---------------------------------+   |

+----------------+              +----------------+         +----------------+
```

### 组件说明:

1.  **用户接口/API层 (User Interface / API Layer)**:
    *   系统的入口，负责接收用户的计算请求。
    *   初期可以是一个简单的命令行接口（CLI），接收一个JSON文件作为输入。
    *   未来可扩展为RESTful API，方便与Web应用或其他服务集成。

2.  **AICFD Agent (核心逻辑)**:
    *   **任务分发器 (Task Dispatcher)**: 解析用户请求，判断是使用`'accurate'`（高精度）模式还是`'fast'`（快速）模式。
    *   **AI代理模型 (AI Surrogate Model)**: 一个预先训练好的神经网络。在`'fast'`模式下，它接收输入参数并立即返回预测的气动系数。
    *   **执行引擎 (Execution Engine)**:
        *   **CFD工作流管理器**: 在`'accurate'`模式下，它负责执行完整的CFD计算流程，包括：创建案例、生成网格、配置求解器、运行计算、分析结果。
        *   **过程监控与日志记录器**: 一个独立的模块，实时跟踪CFD求解器的运行状态，记录日志，并在发生错误或超时时终止流程。

3.  **底层工具与文件 (Tools & Files)**:
    *   **CFD求解器**: 选用 **OpenFOAM**，因其强大的功能、灵活性和完全由文本驱动的特性，非常适合自动化。
    *   **案例文件**: 每个计算任务都会生成一个独立的OpenFOAM案例文件夹。
    *   **日志/报告文件**: 存储详细的运行日志和最终生成的图文报告。

## 4. 技术栈选型

*   **后端/Agent**: Python 3.9+
*   **CFD求解器**: OpenFOAM (v9 or later)
*   **网格生成**: Gmsh (with Python API)
*   **Python核心库**:
    *   **CFD交互**: PyFoam, subprocess
    *   **数据处理**: NumPy, Pandas
    *   **AI**: PyTorch (for training), ONNX (for inference)
    *   **可视化**: Matplotlib, Seaborn
    *   **API (可选)**: FastAPI, Flask
*   **运行环境**: Linux (推荐Ubuntu 20.04/22.04 LTS) 或 Windows with WSL2.
