# OpenVSP功能分析

本文档详细分析了OpenVSP（Open Vehicle Sketch Pad）的飞机设计和计算功能，为SKILL功能增强提供参考。

## 一、OpenVSP功能清单

### 1. 几何建模功能

#### 1.1 参数化几何建模
OpenVSP支持完整的参数化几何建模，包括：

- **机翼建模**
  - 翼型定义（NACA系列、自定义翼型）
  - 翼型沿展向变化
  - 后掠角定义
  - 梯形比定义
  - 扭转角定义
  - 增升装置（襟翼、缝翼、副翼）

- **机身建模**
  - 长径比定义
  - 当量直径定义
  - 截面形状（圆形、椭圆、自定义）
  - 座舱定义

- **尾翼建模**
  - 水平尾翼（平尾）
  - 垂直尾翼（垂尾）
  - 方向舵、升降舵定义

- **发动机建模**
  - 涵道比定义
  - 发动机吊挂位置
  - 进气道形状

- **起落架建模**
  - 前起落架
  - 主起落架
  - 轮距定义

#### 1.2 几何变换
- **平移**：组件位置调整
- **旋转**：组件姿态调整
- **缩放**：组件尺寸调整
- **对称复制**：左右对称生成

#### 1.3 几何组合
- **组件组装**：多个组件组装成完整飞机
- **布尔运算**：组件之间的布尔运算
- **曲面求交**：曲面之间的交线计算

### 2. 气动分析功能

#### 2.1 寄生阻力分析
OpenVSP的寄生阻力分析模块（`parasite_drag.py`）提供：

- **摩擦阻力**
  - 层流摩擦系数计算
  - 湍流摩擦系数计算
  - 雷诺数计算
  - 表面粗糙度修正

- **形状阻力**
  - 压差阻力计算
  - 分离阻力计算
  - 形状因子计算

- **干扰阻力**
  - 组件间干扰计算
  - 干扰因子计算

- **阻力系数分解**
  - CD0分解
  - 各组件阻力贡献
  - 总阻力汇总

#### 2.2 表面补丁分析
OpenVSP的表面补丁分析模块（`surface_patches.py`）提供：

- **表面网格生成**
  - 参数化表面网格
  - 网格密度控制
  - 网格质量检查

- **法向量计算**
  - 表面法向量计算
  - 法向量归一化
  - 法向量可视化

- **曲率分析**
  - 主曲率计算
  - 高斯曲率计算
  - 曲率可视化

#### 2.3 阻力系数计算
- **雷诺数计算**
  - 基于特征长度
  - 基于速度和高度

- **层流/湍流摩擦系数**
  - 层流摩擦系数公式
  - 湍流摩擦系数公式
  - 转捩点计算

- **阻力系数汇总**
  - CD0汇总
  - 各组件CD0
  - 总CD0

### 3. 退化几何功能

#### 3.1 升力面退化
OpenVSP的退化几何模块（`degen_geom_parse.py`）提供：

- **升力面简化**
  - 升力面简化为平板（DegenPlate）
  - 升力面简化为梁（DegenStick）
  - 翼型数据保留

- **质量属性计算**
  - 面积计算
  - 体积计算
  - 惯性矩计算
  - 重心计算

#### 3.2 机身退化
- **机身简化**
  - 机身简化为圆柱
  - 机身简化为圆锥
  - 截面数据保留

#### 3.3 圆盘退化
- **螺旋桨简化**
  - 螺旋桨简化为圆盘（DegenDisk）
  - 圆盘直径定义
  - 圆盘位置定义

#### 3.4 网格退化
- **复杂曲面简化**
  - 复杂曲面简化为网格（DegenMesh）
  - 网格节点保留
  - 网格拓扑保留

### 4. 大气模型功能

#### 4.1 标准大气模型
OpenVSP的大气模型模块（`atmosphere.py`）提供：

- **ISA标准大气**

  - 压力随高度变化
  - 密度随高度变化
  - 声速随高度变化

#### 4.2 非标准大气
- **温度偏差**
  - Delta T定义
  - 温度剖面修正

- **压力偏差**
  - Delta P定义
  - 压力剖面修正

#### 4.3 大气参数计算
- **温度计算**
  - 几何高度转换
  - 地位势高度计算
  - 温度比计算

- **压强计算**
  - 压强比计算
  - 压强值计算

- **密度计算**
  - 密度比计算
  - 密度值计算

- **声速计算**
  - 声速值计算
  - 马赫数转换

- **粘度计算**
  - 绝对粘度计算
  - 动粘度计算
  - Sutherland公式

## 二、OpenVSP与SKILL功能对比

### 2.1 已有功能对比

| 功能类别 | OpenVSP | 现有SKILL | 对应程度 |
|---------|---------|-----------|---------|
| 几何参数定义 | ✅ 完整 | ✅ 完整 | 完全对应 |
| 翼型生成 | ✅ NACA系列 | ❌ 无 | 需要增加 |
| 几何变换 | ✅ 完整 | ❌ 无 | 需要增加 |
| 退化几何 | ✅ 完整 | ❌ 无 | 需要增加 |
| 寄生阻力 | ✅ 详细 | ⚠️ 部分 | 需要增强 |
| 表面分析 | ✅ 完整 | ❌ 无 | 需要增加 |
| 大气模型 | ✅ 完整 | ✅ 完整 | 完全对应 |
| 载荷分析 | ✅ 完整 | ❌ 无 | 需要增加 |
| 旋翼分析 | ✅ 完整 | ❌ 无 | 需要增加 |

### 2.2 功能差距分析

#### 2.2.1 几何建模差距
- **翼型库**：SKILL缺少翼型库和翼型生成功能
- **几何变换**：SKILL缺少几何变换功能
- **几何组合**：SKILL缺少几何组合功能

#### 2.2.2 气动分析差距
- **表面分析**：SKILL缺少表面网格和法向量计算
- **详细阻力分解**：SKILL的阻力分解需要更详细
- **曲率分析**：SKILL缺少曲率分析

#### 2.2.3 退化几何差距
- **退化算法**：SKILL完全缺少退化几何功能
- **质量属性**：SKILL需要从几何计算质量属性

#### 2.2.4 载荷分析差距
- **气动载荷**：SKILL缺少气动载荷计算
- **结构载荷**：SKILL缺少结构载荷计算
- **惯性载荷**：SKILL缺少惯性载荷计算

#### 2.2.5 旋翼分析差距
- **旋翼气动力**：SKILL完全缺少旋翼分析
- **旋翼性能**：SKILL完全缺少旋翼性能分析

3. **创建退化几何模块**
   - 实现升力面退化算法（平板、梁）

   - 实现圆盘退化算法（螺旋桨）
