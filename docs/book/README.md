## 使用指南

### 初学者
1. 从[空气动力学基础理论](./01_aerodynamics_fundamentals.md)开始，了解流体力学和翼型基础
2. 学习[飞机动力学与稳定性理论](./02_aircraft_dynamics_stability.md)，掌握运动方程和稳定性分析
3. 研究[飞机动力学建模理论](./03_aircraft_dynamics_modeling.md)，了解建模方法和仿真技术

### 进阶用户
1. 深入研究各理论文档中的高级主题
2. 理解不同坐标系之间的转换关系
3. 掌握模态分析和控制系统设计方法

### 开发者
1. 参考各理论文档实现计算模块
2. 确保公式实现的正确性
3. 建立完整的验证和测试体系

## 符号说明

### 常用符号
- $\mathbf{V}$：速度矢量
- $\mathbf{F}$：力矢量
- $\mathbf{M}$：力矩矢量
- $\mathbf{\omega}$：角速度矢量
- $\mathbf{I}$：惯性张量
- $\rho$：空气密度
- $p$：压力
- $T$：温度
- $V$：速度
- $M$：马赫数
- $C_L$：升力系数
- $C_D$：阻力系数
- $C_m$：俯仰力矩系数
- $S$：参考面积
- $c$：弦长
- $b$：翼展
- $AR$：展弦比
- $\alpha$：迎角
- $\beta$：侧滑角
- $\phi, \theta, \psi$：欧拉角
- $p, q, r$：角速度分量

### 坐标系
- 下标 $I$：惯性坐标系
- 下标 $b$：机体坐标系
- 下标 $s$：稳定坐标系
- 下标 $w$：风轴坐标系
