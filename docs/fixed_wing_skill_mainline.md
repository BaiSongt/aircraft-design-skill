# 固定翼 Skills 说明书（按全部 SKILL 汇总）

本文档用于把仓库内所有固定翼相关 SKILL 做成一份“面向使用者的说明书”：每个 SKILL 做什么、什么时候用、需要你提供什么、会产出什么。

本文档不会描述任何 SKILL 的内部实现方式、算法步骤或技术路线，仅保留可用于正确调用与验收的用户侧信息。

## 1. 使用约定（用户侧）

- **入口选择**：如果你的目标是“跑一次总体设计并拿到结果/报告/资产”，优先使用 `fixed_wing_overall_sizing_runbook`。
- **输入组织**：推荐用一份输入文件集中承载任务需求、初始假设与可选的外形信息；各子 SKILL 只关注自己需要的信息片段。
- **输出获取**：所有可交付结果以运行输出目录为准（报告、数据、外形资产等）。子 SKILL 通常用于解释、校核、定位问题或补全输入信息。

## 2. SKILL 类型说明

- **Runbook**：告诉你“怎么用、怎么跑、怎么读结果、如何定位问题”。
- **Spec**：告诉你“需要哪些信息、字段的含义与边界、输出应满足哪些验收点”。

## 3. SKILL 目录（全部）

### 3.1 总体入口与扩展入口

#### fixed_wing_overall_sizing_runbook

- 用途：固定翼总体设计的统一入口，输出总体结果与交付物。
- 适用：你想得到一套可用的总体结果（重量、尺寸、性能、约束满足情况等）。
- 你需要提供：任务需求（航程/载荷/巡航点/起降限制等）与一组合理初始假设（例如外形尺度与效率类参数）。
- 你会得到：运行输出目录下的设计数据与报告，以及（如启用）外形与可视化资产。

#### fixed_wing_overall_sizing_spec

- 用途：固定翼总体设计的输入/输出口径说明与验收口径。
- 适用：你不确定输入怎么组织、字段是什么意思、产出应该检查哪些点。
- 你需要提供：你的任务需求与希望约束/优化的关注点。
- 你会得到：字段口径与验收建议，便于把输入补齐并让输出可解释。

#### fixed_wing_advanced_overall_runbook

- 用途：在总体结果可用的前提下，执行更完整的“几何/分析/报告资产”输出流程。
- 适用：你需要更丰富的几何资产、更多图表、或更细的分析结果落盘。
- 你需要提供：在总体输入基础上补充外形信息与相关开关项（若有）。
- 你会得到：更完整的外形资产与扩展报告（以输出目录为准）。

#### fixed_wing_stage2_7_plan

- 用途：对“扩展能力”的功能清单、接口口径与验收标准做规划。
- 适用：你要扩展仓库能力、对齐接口字段、或制定验收标准。
- 你需要提供：你希望扩展/验收的能力范围（例如气动、推进、结构、优化等）。
- 你会得到：清晰的阶段化能力清单与验收口径（不涉及实现路线）。

### 3.2 迭代与敏感性

#### fixed_wing_design_loop_runbook

- 用途：指导如何做总体迭代、如何定位不收敛/不满足的原因、如何调整关键假设。
- 适用：结果不满足需求、或者收敛困难，需要系统化排查与调整策略。
- 你需要提供：一次运行后的输出结果（关键指标与不满足项）以及你可以调整的设计变量范围。
- 你会得到：排查顺序与调整建议（聚焦“如何改输入/约束”，不涉及内部实现）。

### 3.3 约束分析

#### fixed_wing_constraints_spec

- 用途：约束分析的输入信息口径与输出应包含的校核项。
- 适用：你要明确“哪些约束被检查、需要什么输入、输出怎么验收”。
- 你需要提供：与约束相关的任务限制（例如起降、失速、巡航、爬升等）与必要的气动/推进假设。
- 你会得到：约束清单与验收口径，便于解释“卡点在哪里”。

#### fixed_wing_constraints_runbook

- 用途：执行约束校核并给出设计点调整建议。
- 适用：你怀疑某个约束导致方案不可行，或想快速定位卡住的约束。
- 你需要提供：当前方案的关键参数（重量、机翼尺度/载荷、推重比/功率、气动假设等）与任务限制。
- 你会得到：逐条约束的满足情况与改进方向建议。

### 3.4 重量估算

#### fixed_wing_weights_spec

- 用途：重量估算的输入口径与输出验收口径。
- 适用：你要搞清楚重量闭合需要哪些输入，或者要改重量假设模型的使用方式。
- 你需要提供：任务需求、载荷/人员、推进类型与初始重量假设（如有）。
- 你会得到：重量项清单与可解释的验收口径。

#### fixed_wing_weights_runbook

- 用途：执行重量闭合并输出收敛信息。
- 适用：你需要重量结果、或要定位燃油/空重异常的来源。
- 你需要提供：任务需求与一组初始假设（与重量有关的关键参数）。
- 你会得到：重量结果、收敛状态与关键分项摘要（以输出目录为准）。

### 3.5 气动与阻力分解

#### fixed_wing_aero_spec

- 用途：气动模型的输入口径、输出应包含的关键指标与验收口径。
- 适用：你要明确气动假设怎么填、输出怎么解释，或要统一气动口径用于约束/性能。
- 你需要提供：外形尺度信息（或等效几何参数）与巡航工况信息。
- 你会得到：气动相关的关键输出项口径与验收建议。

#### fixed_wing_aero_runbook

- 用途：执行气动一级模型计算与输出检查。
- 适用：你要快速得到气动相关关键参数，或诊断航程/爬升受阻是否来自气动假设。
- 你需要提供：外形尺度信息（或等效几何参数）与巡航工况信息。
- 你会得到：气动关键输出与一致性检查建议。

#### fixed_wing_aero_buildup_spec

- 用途：基于外形信息的阻力分解输入口径与输出验收口径。
- 适用：你不想用拍脑袋的阻力假设，希望阻力来源可追溯、可解释。
- 你需要提供：外形信息（机翼/机身/尾翼等的尺度或等效参数）与工况信息（如适用）。
- 你会得到：阻力分解项口径、以及输出结果应如何验收的说明。

#### fixed_wing_aero_buildup_runbook

- 用途：执行阻力分解计算并输出分项清单。
- 适用：你要拿到可追溯的阻力分项，或要比较不同外形/构型对阻力的影响。
- 你需要提供：外形信息与必要的构型/工况假设。
- 你会得到：阻力分解表与汇总指标（以输出目录为准）。

### 3.6 推进

#### fixed_wing_propulsion_spec

- 用途：推进输入口径与输出验收口径。
- 适用：你不确定推进相关参数怎么组织、或要保证与航程/性能相关计算口径一致。
- 你需要提供：推进类型与关键效率/耗油类参数（按你的推进形式提供）。
- 你会得到：推进口径说明与可用性检查要点。

#### fixed_wing_propulsion_runbook

- 用途：校核推进输入是否可用，并给出修正建议。
- 适用：航程/燃油/性能结果异常时，想先排除推进输入问题。
- 你需要提供：推进类型与关键耗油/效率参数、以及目标工况（如适用）。
- 你会得到：可用性结论与需要补齐/修正的项。

### 3.7 性能

#### fixed_wing_performance_spec

- 用途：性能校核的输入口径与输出验收口径。
- 适用：你要明确性能结果该看哪些指标、需要哪些输入、如何判断是否满足需求。
- 你需要提供：关键工况（巡航/爬升等）与当前方案的重量、气动、推进信息。
- 你会得到：性能输出项口径与验收建议。

#### fixed_wing_performance_runbook

- 用途：执行性能校核并输出不满足项定位建议。
- 适用：你要快速判断方案是否满足巡航/爬升等关键指标，或要定位性能瓶颈。
- 你需要提供：当前方案的重量、气动、推进与目标工况。
- 你会得到：性能结果摘要与改进方向。

### 3.8 稳定与操纵

#### fixed_wing_stability_control_spec

- 用途：稳定与操纵相关输入口径与输出验收口径（含尾翼规模的初始建议口径）。
- 适用：你要把稳定性相关输入补齐，或要统一稳定性结果的验收方式。
- 你需要提供：与重心位置、尾翼规模/力臂相关的信息（可为粗略级别）。
- 你会得到：稳定性相关输出项口径与验收建议。

#### fixed_wing_stability_control_runbook

- 用途：执行尾翼初算并给出稳定性相关的检查建议。
- 适用：你需要一个尾翼规模的起点，或要排查稳定性指标是否明显不合理。
- 你需要提供：当前方案的机翼尺度、尾翼力臂/比例信息与重心相关假设（如有）。
- 你会得到：尾翼规模建议与稳定性检查摘要。

### 3.9 结构与载荷

#### fixed_wing_structures_loads_spec

- 用途：结构与载荷相关输入口径、输出验收口径，以及“结构重量回馈”接口说明。
- 适用：你要把结构可行性纳入总体方案的验收或迭代输入。
- 你需要提供：载荷水平假设与关键几何/重量信息。
- 你会得到：结构/载荷输出口径与验收建议。

#### fixed_wing_structures_loads_runbook

- 用途：执行结构/载荷一级估算并给出结构重量修正建议。
- 适用：你怀疑结构假设导致重量或可行性异常，或希望对结构重量做合理修正。
- 你需要提供：重量规模、载荷水平与关键几何信息。
- 你会得到：结构/载荷量级结果与可能的重量修正建议。

### 3.10 系统

#### fixed_wing_systems_spec

- 用途：定义机载系统配置项（用于覆盖或补充默认系统估算口径）。
- 适用：你需要指定航电/起落架/飞控等系统的重量与位置，或希望系统分项更可控。
- 你需要提供：系统配置清单（按你关心的子系统填写即可）。
- 你会得到：系统配置如何体现在输出数据中的说明与验收要点。

### 3.11 外形（参数化与资产）

#### fixed_wing_shape_parametric_spec

- 用途：定义可重建外形的参数化输入口径与派生口径（面向用户填参）。
- 适用：你要把外形输入从“少量参数”逐步细化为“可重建外形”的结构化输入。
- 你需要提供：机翼/机身/尾翼的几何参数或控制点（可由粗到细）。
- 你会得到：外形输入口径说明与验收点（不包含实现路线）。

#### fixed_wing_shape_parametric_runbook

- 用途：指导如何逐步细化外形输入，并验证可重建/可复现。
- 适用：你要推进外形输入精度，并确保每一步都有可验证的产物。
- 你需要提供：当前层级的外形输入（粗略或详细均可）与期望的细化方向。
- 你会得到：外形细化与验收建议，以及产物查看方式（以输出目录为准）。

#### fixed_wing_shape_detail_spec

- 用途：定义外形详细设计的输入口径与验收标准（翼型/机身剖面/三视图预览等）。
- 适用：你要把外形做到“更接近真实”，并把验收标准写清楚（例如可视化资产必须可用）。
- 你需要提供：更详细的外形定义信息（例如翼型与机身剖面等）。
- 你会得到：详细外形输入口径与验收要求。

#### fixed_wing_shape_detail_runbook

- 用途：生成外形资产并支持外形候选对比（如启用候选搜索）。
- 适用：你需要三视图/网格/导出等资产，或要做多方案外形对比筛选。
- 你需要提供：外形输入（以及候选搜索的数量/随机种子等参数，如适用）。
- 你会得到：外形资产与对比结果（以输出目录与候选输出目录为准）。
