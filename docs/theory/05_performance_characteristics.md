# 飞机性能理论

## 1. 性能概述

对于战斗机而言，所关心的主要飞行性能指标通常包括：

1. **有效载荷**：包括飞行员重量、携带的武器和载弹量
2. **作战半径**：飞行任务剖面所规定的作战半径
3. **航程**：给定巡航高度和巡航速度的航程，或转场航程
4. **最大巡航速度**：给定巡航高度，发动机最大巡航推力状态时的平飞速度
5. **最大平飞速度**：给定高度上，发动机最大推力状态下平飞速度
6. **爬升率**：给定高度上的最大爬升率
7. **实用升限**：飞机爬升率降至5米/秒时所对应的高度
8. **水平加速度性能**：给定高度，飞机从某一速度加速到另一速度所需的时间
9. **最大持续盘旋过载**：在给定高度和速度数情况下的最大持续水平过载
10. **起飞距离**：在给定高度和发动机起飞工作状态下，飞机由静止加速至起飞速度并爬升至安全高度15m所经过的水平距离
11. **着陆距离**：飞机从安全高度15m下滑过渡到地面滑跑直至减速停止所需的水平距离

飞机性能主要取决于飞机的重量特性、气动特性、发动机推力和耗油率特性。

## 2. 场域性能

评价飞机场域性能的主要指标为最大起飞（着陆）距离，而起飞和着陆重量、油门位置、襟翼开度等因素均会影响起降性能。

### 2.1 起降失速速度

失速速度是飞机维持水平直线飞行所需要的最小速度，此时飞机升力系数达到最大。

#### 2.1.1 失速状态受力分析

失速速度状态下的静力图如图所示，在忽略发动机安装角的前提下，其受力平衡关系式如下：

```
L = W × cos(γ)
T = D + W × sin(γ)
```

其中：
- `L`：升力
- `W`：重量
- `γ`：航迹角
- `T`：推力
- `D`：阻力

#### 2.1.2 失速速度计算公式

由于相比于CL，CD一般为小量，因此可以忽略阻力，由此算出的失速速度会更大，不会对飞行产生危险。在简化后可以得到失速速度计算公式为：

```
V_stall = √(2 × W / (ρ × S × CLmax))
```

其中：
- `W`：飞机重量
- `ρ`：空气密度
- `S`：机翼参考面积
- `CLmax`：最大升力系数

**起飞失速速度**：
- 重量依据最大起飞重量计算
- 最大升力系数依据襟翼偏转起飞偏角计算

**着陆失速速度**：
- 重量依据仅剩10%燃油重量的飞机重量计算
- 最大升力系数依据襟翼偏转着陆偏角计算

### 2.2 起飞性能

起飞距离指的是从地面滑跑、起飞抬头到爬升到安全高度所经过的水平距离。

#### 2.2.1 起飞流程

飞机起飞流程大致如下：
1. 发动机进入慢车状态暖机约6min
2. 发动机进入最大起飞推力状态，飞机于起飞跑道从0速度开始地面滑跑
3. 当速度到达抬前轮速度VR，开始抬前轮滑跑，飞机迎角逐渐增大
4. 当速度增大到离地速度VLOF，飞机离开跑道，开始爬升
5. 爬升至安全高度hs（一般取为50ft，即15.4m），此时对应的飞行速度不低于起飞安全速度V2

#### 2.2.2 起飞特征速度

| 起飞特征速度名称 | 符号 | 参考取值 |
|--------------|------|---------|
| 失速速度 | VS | - |
| 抬前轮速度 | VR | 1.1VS |
| 离地速度 | VLOF | 1.12VS |
| 起飞爬升速度 | V2 | ≥1.2 VS |

#### 2.2.3 地面滑跑加速度

地面滑跑状态下的静力图如图所示，在忽略发动机安装角、跑道坡度、风速的前提下，其受力平衡关系式如下：

```
T - D - μ × (W - L) = (W / g) × a
```

解得：
```
a = (T - D - μ × (W - L)) × g / W
```

其中：
- `a`：飞机的加速度
- `μ`：地面滚动摩擦系数，不同跑道地面类型对应不同的取值，混凝土和碎石路面跑道一般取0.02~0.03，计算过程取为0.025
- `α`：迎角，在飞机抬头前为停机角，抬头后为实际迎角
- `g`：重力加速度
- 推力T、阻力D和升力L由发动机和气动分析模型输出

#### 2.2.4 地面滑跑距离

根据上述的飞机加速度可以写出飞机滑跑阶段的距离公式为：

```
S_ground = ∫ V dt = ∫ (V / a) dV
```

其中：
- `V`：速度
- `q`：动压，q = 0.5 × ρ × V²

将上述积分离散化，基于初始速度点、加速度、离散时间可以计算下一个速度点的速度，基于Simpson积分思想，上述积分可以写成离散形式：

```
S_ground = Σ (V_i + V_{i+1}) / (2 × a_i) × ΔV
```

同时，需要说明的是，在抬头段迎角变化过程中，迎角变化率根据抬前轮结束时升力等于重力得到的终点迎角在速度区间内均匀分布的原则确认。

#### 2.2.5 起飞越障段

对于起飞越障段，其计算方式同爬升，在任务性能中介绍。

### 2.3 着陆性能

着陆距离指的是从安全高度开始进近、拉平、接地滑跑直至速度为0的水平距离。

#### 2.3.1 着陆流程

着陆流程大致如下：
1. 发动机在安全高度（一般取为50ft，即15.4m）处于慢车状态
2. 飞机此时速度为进近速度VA，飞机开始进近，同时逐渐拉平，速度逐渐减小
3. 在接地时达到接地速度VTD
4. 飞行员踩刹车，飞机开始作减速滑跑直至停下

#### 2.3.2 着陆特征速度

| 典型着陆速度 | 符号 | 参考取值 |
|------------|------|---------|
| 着陆失速速度 | VS1 | - |
| 进场速度 | Va | 1.2 VS1 |
| 接地速度 | VTD | 1.1 VS1 |

#### 2.3.3 着陆距离计算

着陆距离计算类似起飞距离，分为下降段与着陆滑跑段。着陆滑跑距离与起飞距离的差别主要在襟翼构型，以及地面摩擦系数，在制动的情况下，混凝土和碎石路面跑道一般取0.25~0.75，计算过程取为0.4。

## 3. 任务性能

对于军机，其任务性能多采用作战半径作为其任务性能的指标。在输入参数已经定义过较为详细的任务剖面，此处简化任务剖面来介绍。

### 3.1 任务剖面

典型的对地攻击机任务剖面和战斗机任务剖面包括以下阶段：

1. 地面滑跑
2. 起飞和爬出
3. 从安全高度爬升到1500ft
4. 爬升和下降
5. 巡航
6. 进近和着陆
7. 应急燃油
8. 盘旋等待、侦察和作战

### 3.2 地面滑跑

起飞前的滑出及着陆后的滑入段消耗的燃油量，根据输入的滑跑时间以及对应的推力确定。

假设该滑跑阶段为地面匀速前进，可以根据轮胎对地面的滚动摩擦系数来推算所需推力，如下式：

```
T_taxi = μ × W
```

其中：
- `μ`：地面滚动摩擦系数
- `W`：飞机重量

### 3.3 起飞和爬出

该段起飞及爬升至安全高度50ft，计算可以根据前节起飞过程的计算结果确定消耗的燃油量和时间。

### 3.4 从安全高度爬升到1500ft

该段为起飞场道阶段，假设定速爬升，速度等于安全高度速度加上10节。

对于定速爬升过程，按高度将飞行过程划分为多个爬升段，并认为各段所对应的升阻特性、速度及爬升梯度保持不变。

#### 3.4.1 定速爬升梯度

```
sin(γ) = (T - D) / W
```

#### 3.4.2 定速爬升上升率

```
RC = V × sin(γ)
```

#### 3.4.3 各段飞行时间

```
Δt = Δh / RC
```

若高度的单位为米（m），速度的单位为米/秒（m/s），耗油率的单位为1/小时（1/h），则各爬升段耗油量可以表示为下式：

```
Δfuel = T × SFC × Δt
```

其中：
- `T`：各段的当前推力
- `Δfuel`：各段的耗油量（kg）

### 3.5 爬升和下降

#### 3.5.1 爬升计划

爬升计划定义为爬升过程中用于指定初始重量、配置和推力(功率)设置的速度/高度组合序列。

飞机在爬升阶段发动机保持最大爬升的挡位爬升，一般按照保持某一表速爬升（例如300节），直到转换高度。

同样按高度将飞行过程划分为多个爬升段，并认为各段所对应的升阻特性、速度及梯度保持不变。由输入的爬升剖面参数确定各个高度下的速度，然后根据下式确定各小段的爬升时间：

```
Δt = Δh / RC
```

#### 3.5.2 飞行距离

```
Δs = V × cos(γ) × Δt
```

#### 3.5.3 爬升各段消耗的燃油

爬升各段消耗的燃油可以由发动机的推力、耗油率及各段航时确定。

#### 3.5.4 下降阶段

飞机下降阶段计算方法同爬升阶段类似，不同在于下降过程中发动机保持空中慢车状态，其它计算公式同爬升阶段相同。

### 3.6 巡航

计算飞机巡航段性能时，按时间将巡航飞行过程划分为若干巡航段，并认为每个航段内的升力系数和阻力系数保持不变。

根据飞机的实时重量可以确定各巡航段的升力系数，由当地极曲线求得阻力系数，从而确定推力T。

根据各巡航段的航时、推力及耗油率即可确定该段的耗油量。将各巡航段的飞行距离和耗油量相加即可得到整个巡航阶段的飞行距离和耗油量。

### 3.7 进近和着陆

进近段按等速下降计算，速度为1.3倍的着陆安全速度，即V_approach = 1.3 × V_stall_landing，其计算过程与下降段计算方法相同。

### 3.8 应急燃油

应急燃油一般按任务燃油或总燃油的一定比例系数确定，该比例系数由用户确定。一般取总燃油6%。

### 3.9 盘旋等待、侦察和作战

飞机盘旋等待、侦察和作战按盘旋计算，盘旋时间由用户输入，盘旋速度为久航马赫数，久航马赫数由飞机重量、当前高度下最大升阻比（L/D）max确定，然后根据盘旋公式可确定消耗的油量如下：

```
fuel_loiter = W_initial × (1 - exp(-SFC × t / (L/D)))
```

其中：
- `W_initial`：盘旋初始时飞机重量
- `SFC_loiter`：盘旋耗油率
- `t`：盘旋时间
- `(L/D)`：盘旋时升阻比

### 3.10 燃油迭代计算

若以预设任务半径作为输入，则先假定初始燃油质量，基于初始燃油重量计算全机重量，根据此任务半径计算此重量下的最小燃油消耗，若最小燃油消耗与初始燃油重量的误差在合理范围内，则认为收敛；若相差较大，则以计算得到的最小燃油消耗为下一轮迭代的初始燃油质量，进行多轮迭代，直至收敛。

## 4. 设计点性能

设计点性能主要包括飞机在设计工况下的特定飞行性能，包括飞机的海平面最大爬升率，实用升限，最大平飞速度等和发动机推力相关的性能，以及巡航升阻比和转弯半径等和气动力关联紧密的性能。

### 4.1 爬升速率和爬升梯度

#### 4.1.1 爬升速率定义

爬升速率常简称为爬升率，定义为几何高度随时间变化的速率，其值等于航迹速度的竖直分量，以Vy表示。

#### 4.1.2 爬升梯度定义

爬升梯度定义为单位水平移动距离的高度变化，常用百分比表示，也可以表示为航迹爬升角的正切。

#### 4.1.3 爬升速率和爬升梯度计算过程

a. 首先计算指定高度、不同马赫数下保持平飞所需要的升力系数：

```
CLc = Wc / (0.5 × ρ × V² × S)
```

其中：
- `CLc`：平飞升力系数
- `Wc`：根据任务剖面决定的给定高度下的整机重量，计算海平面最大爬升率时即可近似为最大起飞重量

b. 其次，调用气动分析模型数据库，用多项式拟合得到不同飞行马赫数下的极曲线。根据极曲线方程，计算该升力系数所对应的阻力系数CDc，从而计算出该马赫数下平飞需用推力：

```
T_required = D = 0.5 × ρ × V² × S × CDc
```

c. 通过调用发动机模型生成的推力特性数据库，拟合数据得到发动机在对应油门、高度和马赫数下的推力。应用简单推力法，即可得到飞机的剩余推力：

```
T_excess = T_available - T_required
```

d. 最后，计算指定高度、不同马赫数的爬升梯度和爬升率：

```
sin(γ) = T_excess / W
Vy = V × sin(γ)
```

其中：
- `W`：飞机爬升起始时刻的重量

计算不同马赫数下的Vy，从中选取一个最大的值，即为该高度下的最大爬升率。

### 4.2 实用升限

#### 4.2.1 升限定义

升限是指飞机所能达到的最大平飞高度，其大小受到外界气压和氧气浓度的影响。当外界气压过小和氧气浓度过低时，发动机无法正常工作，飞机很难再进行加速飞行。

#### 4.2.2 实用升限计算

常用作参考的升限为绝对升限和实用升限。

- **绝对（理论）升限**：定义为在给定的配置、重量、速度和推力设置下，最大稳态爬升速率为0的高度
- **实用升限**：定义为在给定的配置、重量、速度和推力设置下，对亚声速飞行，最大稳态爬升速率衰减至0.5m/s的飞行高度

利用公式计算爬升率的方法，可以先求得各高度下对应的最大爬升率，通过对一组高度和对应爬升率的数据进行拟合插值，可以求得最大爬升率对应为0.5m/s（亚声速飞机）或5m/s（超声速飞机）的飞行高度，即为实用升限。

### 4.3 转弯半径

飞机定常水平转弯的能力也是飞行性能中关键的一部分。协调转弯定义为飞机在Y轴方向净加速度为0。

#### 4.3.1 持续转弯状态受力分析

```
L × cos(φ) = W
L × sin(φ) = m × V² / R
```

其中：
- `φ`：滚转角
- `R`：转弯半径
- `m`：飞机质量
- `V`：飞行速度

#### 4.3.2 过载系数

```
n = L / W = 1 / cos(φ)
```

#### 4.3.3 转弯半径计算公式

```
R = V² / (g × √(n² - 1))
```

#### 4.3.4 最小转弯半径

最小转弯半径计算公式：
```
R_min = V² / (g × √(n_max² - 1))
```

其中：
- `n_max`：最大过载
