# 飞机发动机特性理论

## 1. 发动机特性概述

发动机是一架飞行器的重要部件，对飞行性能、安全性和效率起着关键作用。推力特性决定了飞行器的速度域与机动能力，耗油特性直接影响飞机的作战半径与飞行成本。分析发动机特性是性能计算的基础。

## 2. 推力特性

发动机推力主要取决于飞行速度、高度和发动机工作状态。

### 2.1 推力基本公式

在给定高度、速度和发动机工作状态条件下，发动机推力T可表示为：
```
T = α × T_SL
```

其中：
- `α`：随高度和速度的变化的推力系数
- `T_SL`：海平面静推力

### 2.2 涡扇发动机推力模型

参考Mattingly，发动机的最大（加力）推力随马赫数、高度的变化可以用一个简单的代数方程模型初步估计，该代数方程的系数根据2000年以后的先进发动机的预期性能拟合而来。

该模型通过无量纲的温度比、压强比以及另一个无量纲参数TR来计算，对于小涵道比的涡扇发动机，具体如下：

#### 2.2.1 基本参数定义

**温度比TR**：
```
TR = T_t / T_SL
```

其中：
- `T_t`：巡航点的总温
- `T_SL`：海平面的静温

**温度比θ**：
```
θ = T / T_SL
```

其中：
- `T`：该高度、速度下的总温
- `T_SL`：海平面的静温

**压力比δ**：
```
δ = P / P_SL
```

其中：
- `P`：该高度、速度下的总压
- `P_SL`：海平面的静压

#### 2.2.2 加力状态推力系数

**计算公式**：
```
α_afterburner = (1 - 0.3 × (M - 1) + 0.2 × (M - 1)²) × (δ / θ^0.8)^0.7
```

其中：
- `M`：马赫数
- `δ`：压力比
- `θ`：温度比

#### 2.2.3 未加力状态推力系数

**计算公式**：
```
α_mil = (1 - 0.6 × (M - 1) + 0.1 × (M - 1)²) × (δ / θ^0.8)^0.7
```

### 2.3 油门杆位置控制

飞行器加力状态和非加力状态下的推力计算如上，通过油门杆可以控制发动机的转速，从而改变发动机的推力或功率。

油门可以在几个特殊挡位之间连续变化。特殊挡位主要指：
- 最大工作（对应最大起飞推力）
- 最大连续
- 最大爬升
- 最大巡航
- 慢车

在油门、转速与推力三者之间没有确定关系的情况下，可以近似认为油门是线性的，即认为推力随油门位置按正比关系变化。

**涡扇发动机典型油门位置对应的比例系数参考值**：

| 工作状态 | 比例系数 |
|---------|---------|
| 最大工作 | 1.0 |
| 最大连续 | 0.85 |
| 最大爬升 | 0.82 |
| 最大巡航 | 0.80 |
| 慢车 | 0.05 |

### 2.4 推力随高度变化

推力随高度的变化主要受大气密度和温度的影响：

**高度修正系数**：
```
η_h = (ρ / ρ_SL)^n
```

其中：
- `ρ`：该高度的空气密度
- `ρ_SL`：海平面空气密度
- `n`：经验指数，通常取0.7~0.9

### 2.5 推力随速度变化

推力随速度的变化主要受马赫数的影响：

**速度修正系数**：
```
η_M = 1 - k_M × (M - M_opt)^2
```

其中：
- `M`：马赫数
- `M_opt`：最佳马赫数
- `k_M`：经验系数

## 3. 耗油率特性

发动机耗油率同样取决于飞行速度、高度和发动机工作状态。

### 3.1 单位推力耗油率定义

单位推力耗油率定义为单位时间产生单位推力的燃油消耗量，单位为（N/N/h）。

### 3.2 涡扇发动机耗油率模型

参考Mattingly同样对耗油率提出了简单的估算模型。对于小涵道比涡扇发动机，具体如下：

#### 3.2.1 加力状态单位推力耗油率

**计算公式**：
```
SFC_afterburner = SFC_SL × (1 + 0.5 × (M - 1)) × θ^0.5
```

其中：
- `SFC_SL`：海平面静耗油率
- `M`：马赫数
- `θ`：温度比

#### 3.2.2 未加力状态单位推力耗油率

**计算公式**：
```
SFC_mil = SFC_SL × (1 - 0.3 × (M - 1) + 0.1 × (M - 1)²) × θ^0.5
```

其中：
- `θ`：该高度的静温比海平面的静温

### 3.3 非设计点耗油率

上述是设计点的耗油率特性，而对于油门杆位置非最大时的耗油率特性，根据Howe提出的发动机非设计点计算方法，假设巡航工作状态，即0.8油门杆位置为设计点位置，其余非设计点单位推力耗油率均有所增加。

**计算公式**：
```
SFC_non_design = SFC_design × (1 + k_throttle × (1 - throttle_ratio)^2)
```

其中：
- `SFC_design`：设计点耗油率
- `throttle_ratio`：油门杆比例
- `k_throttle`：经验系数，通常取0.2~0.5

### 3.4 耗油率随高度变化

耗油率随高度的变化主要受大气温度的影响：

**高度修正系数**：
```
η_SFC_h = (T / T_SL)^0.5
```

其中：
- `T`：该高度的空气温度
- `T_SL`：海平面空气温度

## 5. 发动机与飞机的匹配

### 5.1 推力需求计算

**平飞需用推力**：
```
T_required = D = 0.5 × ρ × V² × S × CD
```

其中：
- `ρ`：空气密度
- `V`：飞行速度
- `S`：机翼参考面积
- `CD`：阻力系数

**爬升需用推力**：
```
T_climb = T_required + W × sin(γ)
```

其中：
- `W`：飞机重量
- `γ`：爬升角

### 5.2 推力余度

**推力余度**：
```
margin = (T_available - T_required) / T_required × 100%
```

其中：
- `T_available`：可用推力
- `T_required`：需用推力

### 5.3 燃油消耗计算

**燃油流量**：
```
fuel_flow = T × SFC
```

其中：
- `T`：推力
- `SFC`：耗油率

**燃油消耗量**：
```
fuel_consumed = ∫ fuel_flow dt
```

## 6. 发动机选型考虑因素

### 6.1 推力等级

根据飞机的推重比要求选择合适的推力等级：
- 战斗机：推重比 > 1.0
- 运输机：推重比 0.25~0.35
- 通用航空飞机：推重比 0.2~0.3

### 6.2 耗油率

耗油率直接影响航程和续航时间，应选择耗油率较低的发动机。

### 6.3 涵道比

- 小涵道比（<1）：适合高速、高推重比应用，如战斗机
- 大涵道比（>5）：适合低速、高效率应用，如运输机

### 6.4 可靠性和维护性

考虑发动机的可靠性、维护性和全寿命周期成本。
