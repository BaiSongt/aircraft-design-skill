# 飞机设计参数理论

## 1. 翼型参数

### 1.1 翼型几何参数

翼型的几何形状决定了翼型的气动特性，对整个机翼的气动特性有着重要影响。翼型几何形状的特征可用以下参数描述：

- **最大相对厚度**：翼型最大厚度与弦长的比值
- **最大相对弯度**：翼型中弧线最大弯度与弦长的比值
- **前缘半径**：翼型前缘的曲率半径

## 2. 机翼参数

### 2.1 机翼参考面积 Sref

机翼参考面积是指"参考机翼形状"的面积。一般用梯形作为参考机翼形状，并且参考机翼的根部一直延伸至机身对称线。

**确定方法**：
- **基本梯形方法**：将实际机翼简化为梯形
- **等效面积方法**：保持实际机翼面积不变

### 2.2 机翼展弦比 AR

机翼展弦比用来反映机翼展向长度（展长）与弦向长度（弦长）的比值。

**计算公式**：
```
AR = b² / Sref
```

其中：
- `Sref`：机翼参考面积
- `b`：机翼展长

### 2.3 机翼后掠角

机翼后掠角Λ的定义一般有两种：

- **前缘后掠角 ΛLE**：机翼前缘与垂直于机身对称线的夹角
- **四分之一弦线后掠角 Λ1/4**：机翼1/4弦线与垂直于机身对称线的夹角

**使用规则**：
- 超声速飞机设计：采用前缘后掠角ΛLE
- 亚声速飞机设计：采用四分之一弦线的后掠角Λ1/4

### 2.4 机翼梯形比 λ

梯形比（也称梢根比）是参考机翼的翼梢处弦长与翼根处弦长的比值。

**计算公式**：
```
λ = Ct / Cr
```

其中：
- `Ct`：翼梢处弦长
- `Cr`：翼根处弦长

λ越小，表示翼梢处弦长越短。

### 2.5 机翼安装角 iW

安装角表征机翼与机身在侧视图上的几何关系。安装角是指机翼根弦与飞机纵轴线之间的夹角。

**设计原则**：
- 机翼安装角设计应使机身在巡航状态的阻力最小

## 3. 增升装置参数

### 3.1 襟翼类型

襟翼类型与尺寸对飞机低速构型的最大升力系数有密切关系。

**前缘襟翼类型**：
- 简单前缘襟翼
- 前缘缝翼
- 克鲁格襟翼

**后缘襟翼类型**：
- 简单后缘襟翼
- 开裂襟翼
- 后退式襟翼
- 单缝襟翼
- 双缝襟翼
- 三缝襟翼
- 富勒襟翼

### 3.2 襟翼尺寸

襟翼尺寸可用襟翼在机翼上的展向和弦向的占比来定义：

- **弦长比例**：襟翼弦长占机翼弦长的比例
- **展长比例**：襟翼展长占机翼展长的比例

### 3.3 襟翼偏转角

- **起飞偏转角**：通常为15度
- **着陆偏转角**：通常为35度

偏转角增大，会使得最大升力系数增大，失速速度减小，但会增加阻力系数。

## 4. 机身参数

### 4.1 机身长径比

机身长径比是机身长度与当量直径的比值。

### 4.2 机身当量直径

**计算公式**：
```
D_eq = 2 × √(Sfmax / π)
```

其中：
- `Sfmax`：机身的最大横截面面积

## 5. 尾翼参数

尾翼外形的定义与机翼外形的定义类似，包括：

### 5.1 水平尾翼参数
- 翼型
- 面积
- 展弦比
- 后掠角
- 梯形比
- 安装角

### 5.2 垂直尾翼参数
- 翼型
- 面积
- 展弦比
- 后掠角
- 梯形比
- 安装角

## 6. 发动机参数

### 6.1 涵道比

发动机的涵道比定义为涡轮风扇发动机的外涵道与内涵道的空气流量之比。

**影响**：
- 涡扇发动机重量与涵道比有关
- 推力特性与涵道比有关
- 耗油率与涵道比有关

## 7. 等效机翼方法

由于工程算法通常针对单段梯形翼，而在实际构型中，通常为多段梯形翼，且每段梯形翼的后掠角不同，因而需要假设一个单段梯形翼与实际的多段梯形翼等效。

### 7.1 等效原则

保证等效前后机翼：
- 参考面积相同
- 展长相同
- 梯形比相同

### 7.2 后掠角计算

后掠角基于每段梯形翼的0.5弦长后掠角面积加权确定：

**前缘后掠角计算**：
```
ΛLE = Λ0.5 + arctan((4 × (1-λ) / (AR × (1+λ))))
```

其中：
- `Λ0.5`：0.5弦长后掠角（面积加权）
- `AR`：展弦比
- `λ`：梯形比
