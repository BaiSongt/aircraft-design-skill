- 静操纵性分析
- 动操纵性分析
- 操稳参数汇总表

## 理论体系架构

### 三层架构

飞机设计采用三层架构：

1. **设计参数层**：定义飞机的基本几何和设计变量
2. **特性层**：基于设计参数计算气动、重量、发动机等特性
3. **指标层**：基于特性层计算性能、操稳等指标

### 数据流向

```
设计参数 → 特性层 → 指标层
   ↓          ↓          ↓
几何参数   气动特性   性能指标
           重量特性   操稳指标
           发动机特性
```

## 计算流程

### 1. 几何建模
- 输入设计参数
- 生成几何模型
- 计算等效机翼参数

### 2. 特性计算
- 气动特性计算（升力线斜率、阻力分解、极曲线）
- 重量特性计算（结构重量、系统重量、总重）
- 发动机特性计算（推力模型、耗油率模型）

### 3. 性能分析
- 场域性能（起飞、着陆）
- 任务性能（航程、航时、燃油消耗）
- 设计点性能（爬升率、升限、转弯）

### 4. 操稳分析
- 静稳定性（纵向、航向、横向）
- 动稳定性（模态分析）
- 操纵性（配平、响应）
