# 飞机气动特性理论

## 1. 气动特性概述

气动升阻特性包括干净构型的升阻特性、以及低速构型偏转增升装置后的升阻增量。应用工程计算方法，可建立这些升阻特性与设计参数之间的定量关系。

## 2. 干净构型升力特性

### 2.1 升力线斜率 CLα

升力线斜率计算参考Raymer进行计算。

#### 2.1.1 亚声速升力线斜率

升力主要由机翼产生。根据低速薄翼型理论，翼型的升力线斜率为2π（1/rad）。翼型的流场是一种二维流场，而机翼的流场是三维流场，存在气流的三维效应，因此机翼的升力线斜率要小于翼型的升力线斜率。

**计算公式**：
```
CLα = (2π × AR / (2 + √(4 + AR² × β² × (1 + tan²Λmaxt) / (1 + (AR × β / (1 + tan²Λmaxt))²)))) × (1/β) × F
```

其中：
- `Λmaxt`：机翼的翼型最大厚度线的后掠角，可近似取1/2弦处后掠角
- `AR`：展弦比
- `Sref`：机翼参考面积
- `Se`：机翼外露的投影面积（机翼参考面积减去被机身覆盖的面积）
- `1/β`：亚声速压缩性形状因子，β = √(1 - M²)
- `M`：马赫数
- `F`：机身升力影响系数

**机身升力影响系数F**：
```
F = 1 + (0.025 × (d/b)² × AR / (1 + (d/b)²))
```

其中：
- `d`：机身当量直径
- `l`：机翼展长

#### 2.1.2 超声速升力线斜率

根据薄翼型超声速理论，薄翼型的升力线斜率为：
```
CLα_2D = 4 / √(M² - 1)
```

机翼的升力线斜率可用超声速线化理论和三维流场效应修正的办法来估算。对于实际的机翼，要考虑展弦比AR、前缘后掠角ΛLE、梯形比λ对升力线斜率的影响。

**计算步骤**：
1. 根据梯形比λ的大小选定对应的曲线图
2. 计算 `β × cot(ΛLE)`，若小于1，应用左半部的曲线图，根据 `β × cot(ΛLE)` 和 `AR × β`，查出CNα；若大于1，取其倒数，根据右半部的曲线图，查出CN

**注意**：
- CNα是基于机翼外露的投影面积Se来定义的
- 如果CNα是基于机翼参考面积Sref来定义，升力线斜率需要乘以Se/Sref
- 若考虑机身的影响，升力线斜率需乘以机身升力影响系数F

#### 2.1.3 跨声速升力线斜率

跨声速时，机翼的升力线斜率CLα与Ma数之间呈现较强的非线性关系，还没有较精确的工程估算方法。

**近似办法**：
1. 首先在亚声速范围内（Ma < 0.9）计算出Ma与CLα之间的曲线关系
2. 在超声速范围内（Ma >1.3）计算出Ma与CLα之间的曲线关系
3. 在跨声速区范围内（0.9 < Ma < 1.3），亚声速段曲线和超声速段曲线进行延伸和平滑过渡

### 2.2 干净构型最大升力系数 CLmax

干净构型的最大升力系数通过给定的失速迎角进行估计。

### 2.3 干净构型零迎角升力系数 CL0

翼型弯度在超声速不产生升力，即便考虑到起降升力需求增加弯度，反而会对超声速巡航波阻产生很大的影响，所以超声速飞行器一般采用简单的对称翼型，而对称翼型的零迎角升力系数一般为0，在三维效应的干扰下可能存在些许偏差，但此处假设零迎角升力系数为0是合理的。

### 2.4 涡升力修正

高速飞行器由于其巡航速度大，导致其机翼面积通常不会很大，引起起降过程中升力不足的缺陷，而涡升力正是弥补起降升力的措施。

**计算公式**（Purvis提出）：
```
CL_vortex = CL_vortex_LE + CL_vortex_SE
```

其中：
- `CL`：机翼不考虑涡升力的升力系数
- `CL_vortex_LE`：机翼前缘吸力产生的涡升力系数
- `CL_vortex_SE`：机翼侧缘产生的涡升力系数

**前缘涡升力系数**：
```
CL_vortex_LE = CT × sin²(α) × cos(α)
```

其中：
- `α`：对应迎角
- `AR`：机翼展弦比
- `Λ_strake`：边条翼后掠角
- `CT`：边条翼相关系数

**侧缘涡升力系数**：
```
CL_vortex_SE = (π × AR / 2) × (Ct / b) × sin²(α)
```

其中：
- `Ct`：翼梢弦长
- `b`：机翼展长
- `K`：常数，取为4.91924

## 3. 干净构型阻力特性

根据物体与空气之间的相互作用，气动阻力来源于边界层的表面切向力和物体表面的压力引起的前后压差。

### 3.1 阻力分类

通常将飞机的阻力分为：

**零升阻力**：
- 各部件摩擦阻力
- 各部件形状阻力（压差阻力）
- 部件之间的干扰阻力
- 杂项阻力
- 超声速波阻（Ma > 1）

**升致阻力**：
- 诱导阻力
- 黏性升致阻力
- 与升力相关的超声速波阻（Ma > 1）

**压缩性阻力**：
- 局部激波引起的压差阻力

**配平阻力**：
- 保持力矩平衡引起的阻力

### 3.2 亚声速零升阻力

亚声速飞机的零升阻力估算的基本思路是：

1. 首先计算飞机各部件（机身、机翼、尾翼等）的摩擦阻力
2. 根据各部件形状特征，用形状因子乘以各部件的摩擦阻力来反映压差阻力
3. 根据总体布局型式，用干扰因子来计算气动干扰阻力
4. 根据飞机类型和特征，再加上各种杂项阻力以及漏气和突出物引起的阻力

**计算公式**：
```
CD0 = Σ(Cfi × Sweti × FFi × Qi) + CDmisc
```

其中：
- `Cfi`：第i个部件表面摩擦系数
- `Sweti`：第i个部件表面的面积（外露面积）
- `FFi`：第i个部件的形状因子
- `Qi`：第i个部件的干扰因子
- `CDmisc`：杂项阻力系数

#### 3.2.1 摩擦系数 Cf

各部件表面与空气之间的摩擦系数，可按空气流过平板时的摩擦系数来估算。

**层流摩擦系数**：
```
Cf_laminar = 1.328 / √(Re)
```

**湍流摩擦系数**：
```
Cf_turbulent = 0.074 / Re^0.2
```

其中`Re`为雷诺数。在湍流计算计入了马赫数对摩擦系数的影响。

**混合边界层摩擦系数**：
```
Cf = (1 - n_laminar) × Cf_turbulent + n_laminar × Cf_laminar
```

其中`n_laminar`为边界层中层流比例。

**层流比例典型值**：

| 飞机类型 | 机身层流比例 | 机翼层流比例 |
|---------|------------|------------|
| 通用航空飞机（普通金属表面） | 0% | 10% |
| 通用航空飞机（光滑金属表面） | 10% | 35% |
| 喷气客机（金属表面） | 5% | 10% |
| 军用飞机（涂迷彩色） | 0% | 0% |

#### 3.2.2 形状因子 FF

形状因子是一个经验系数，用于反映气流流过飞机表面时边界层分离引起的压差阻力。

**翼面类部件形状因子**：
```
FF = [1 + 0.6/(x/c + 0.6) × tc + 100 × tc^4] × [1 + 1.5 × (M × cos(Λm))^(1.68) × (AR × cos²(Λm))^0.31]
```

其中：
- `tc`：机翼平均的相对厚度
- `x/c`：翼型最大厚度处的相对位置
- `Λm`：最大厚度位置连线的后掠角
- `M`：飞行Ma数

**机身类部件形状因子**：
```
FF = 1 + 60/f^3 + 0.0025 × f
```

其中`f`为机身（或短舱和外挂物）的长径比。

**短舱和外挂物形状因子**：
```
FF = 1 + 0.35/f
```

如果机身剖面形状为矩形或方形，形状因子会增加30%～40%。

#### 3.2.3 干扰因子 Q

飞机部件之间的气流可能存在干扰，产生额外的压差阻力。

**干扰因子取值**：
- 上单翼、中单翼和具有很好整流的下单翼布局：Q = 1.0
- 没有整流的下单翼布局：Q = 1.1～1.4
- 机身：Q = 1
- 常规尾翼布局：Q = 1.04～1.05
- V尾布局：Q = 1.03
- H形尾翼：Q = 1.08

#### 3.2.4 杂项阻力 CDmisc

**底阻**（亚声速）：
```
CD_base = 0.1 × Abase / Sref
```

**底阻**（超声速）：
```
CD_base = 0.2 × Abase / Sref
```

其中`Abase`为部件尾部截面的面积。

**驾驶舱风挡阻力**：
```
CD_cockpit = 0.2 × A_windshield / Sref  （平滑融入机身的风挡）
CD_cockpit = 0.8 × A_windshield / Sref  （非平滑融入机身的风挡）
```

其中`A_windshield`为驾驶舱的风挡的迎风面积。

**通气口和凸起物引起的阻力**：

| 飞机类型 | 零升阻力的占比 |
|---------|--------------|
| 螺旋桨飞机 | 5~10% |
| 喷气运输机或轰炸机 | 2~5% |
| 战斗机 | 10~15% |
| 隐身战斗机 | 3~5% |

### 3.3 升致阻力

升致阻力是指机翼升力引起的阻力。它通常包括两个部分：
1. 不考虑空气黏性的升致阻力，也就是诱导阻力
2. 由于空气黏性导致的升致阻力，即黏性升致阻力

**计算公式**：
```
CDi = K' × (CL - CLmin)² + K'' × (CL - CLmin)²
```

其中：
- `K'`：诱导阻力因子
- `K''`：黏性升致阻力因子
- `CLmin`：阻力最小时对应的升力系数

对于有弯度的翼型，CLmin ≠ 0；对于对称翼型，CLmin = 0。

**简化公式**：
```
CDi = K × (CL - CLmin)²
```

其中`K`为升致阻力因子。

#### 3.3.1 亚声速升致阻力因子

**计算公式**：
```
K = 1/(π × e × AR) + K_wing + K_fuselage
```

其中：
- `AR`：机翼展弦比
- `e`：奥斯瓦尔德效率因子
- `K_wing`：机翼形状因子
- `K_fuselage`：机身影响因子

**奥斯瓦尔德效率因子**：
```
e = 1.78 × (1 - 0.045 × AR^0.68) - 0.64
```

### 3.4 超声速零升阻力

超声速的零升阻力的计算思路与亚声速情况类似，主要区别是要另外计算波阻。

**计算公式**：
```
CD0_supersonic = Σ(Cfi × Sweti) + CDmisc + CDw
```

其中：
- 右边第一项为摩擦阻力系数
- `CDmisc`为杂项阻力系数
- `CDw`为零升波阻系数

**波阻计算**：
采用NASA拉里斯研究中心开发的WaveDrag程序进行计算，主要依据面积率进行计算。

### 3.5 跨声速压缩性阻力

对于高亚声速飞机，当飞机的飞行速度超过临界Ma数时，飞机表面的流场会出现局部超声速区。此时，飞机表面上既有亚声速区域，又有超声速区域，也就是存在跨声速流场。

**计算公式**：
```
CD_compression = 20 × (M - Mdd)^n
```

其中：
- `M`：飞行Ma数
- `ΔM`通常取0.05
- `n`大约为2.5
- `Mdd`：阻力发散马赫数

**阻力发散马赫数**：
对于给定的升力系数，随着Ma数增加，当压缩性阻力达到0.002（即20个单位阻力，1个单位阻力=0.0001）时对应的Ma数。

**估算公式**：
```
Mdd = Mcr + 0.05
```

**临界马赫数Mcr估算**：
```
Mcr = Mref × tc^(1/3) - 0.1
```

其中：
- `tc`：机翼平均的相对厚度
- `Mref`：翼形设计的技术水平因子，通常取值在0.85~0.95之间

## 4. 低速构型升阻增量计算

### 4.1 升力增量计算

飞机在起降阶段处于低速构型，即增升装置（包括前缘和后缘增升装置）展开的外形。

**升力系数增量**：
```
ΔCL_flap = (S_flap / Sref) × cos²(ΛHL) × ΔCLmax_2D
```

其中：
- `S_flap`：机翼流场被增升装置所影响的面积
- `ΛHL`：增升装置铰链线的后掠角
- `ΔCLmax_2D`：二维情况下的各类增升装置的升力系数的增量

**二维襟翼升力系数增量**：

| 增升装置 | 最大升力系数增量的典型值 |
|---------|---------------------|
| 简单后缘襟翼（相对弦长0.2） | 0.8 |
| 简单后缘襟翼（相对弦长0.4） | 1.1 |
| 开裂襟翼（相对弦长0.2） | 0.9 |
| 开裂襟翼（相对弦长0.4） | 1.4 |
| 单缝襟翼（相对弦长0.2） | 1.2 |
| 单缝襟翼（相对弦长0.4） | 1.8 |
| 双缝襟翼（相对弦长0.4） | 2.5 |
| 三缝襟翼（相对弦长0.4） | 2.9 |
| 富勒襟翼（相对弦长0.2） | 1.2 |
| 富勒襟翼（相对弦长0.4） | 1.8 |
| 简单前缘襟翼（相对弦长0.15） | 0.5 |
| 前缘缝翼（相对弦长0.18） | 1.0 |
| 克鲁格襟翼（相对弦长0.20） | 0.8 |

### 4.2 阻力增量计算

低速构型阻力增量主要来自于增升装置偏转引起的增量以及起落架放下产生的增量。

#### 4.2.1 襟翼零升阻力增量

**计算公式**：
```
ΔCD0_flap = F_flap × (S_flap / Sref) × (δ_flap / 10)^2
```

其中：
- `F_flap`：襟翼的形状因子，对于简单襟翼取0.0144，对于有缝的襟翼取0.0074
- `S_flap`：襟翼所影响的机翼面积
- `δ_flap`：襟翼的偏转角（单位为度），需大于10，小于10时，近似认为其零升阻力增量可忽略不计

#### 4.2.2 襟翼诱导阻力增量

**计算公式**：
```
ΔCDi_flap = kf × (ΔCL_flap)² / (π × e × AR)
```

其中：
- `ΔCL_flap`：襟翼展开后的升力系数的增量
- `kf`：经验系数
  - 当襟翼展长与机翼展长一样时，取kf = 0.14
  - 当襟翼展长为机翼展长一半时，取kf = 0.28
  - 其它情况可通过插值计算
