# 固定翼稳定与操纵方案（Spec）

## 目标

- 用尾容积系数法给出水平尾翼/垂直尾翼面积初值
- 为配平阻力与 CG 包线分析预留接口（后续扩展）

## 输入

- 机翼几何：`S`, `b`, `cbar`
- 尾臂：`lh_m`, `lv_m`
- 尾容积系数：`vh`, `vv`

## 输出

- `Sh`, `Sv`：水平/垂直尾翼面积初算
- 稳定性检查项清单（占位）：静稳定裕度、操纵面余度、配平阻力
